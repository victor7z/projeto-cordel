# Cordel Moderno 📜

Página criada para o curso de HTML5 e CSS3 do **Curso em Vídeo** (professor Gustavo Guanabara). Ela apresenta o poema **Cordel Moderno**, de Milton Duarte, em seções de texto com imagens de fundo.

## 🎯 O que pratiquei

- Estrutura de uma página com HTML
- Estilização com CSS
- Imagens de fundo em seções
- Organização do texto para leitura

## 🛠️ Tecnologias

HTML5 · CSS3

## ▶️ Como ver

Baixe o repositório e abra o arquivo `index.html` no navegador.

## 🙏 Créditos

Projeto de estudo do **Curso em Vídeo**. O poema "Cordel Moderno" é de **Milton Duarte**.
